# 关屏（Windows）

一个托盘小工具：**把屏幕关掉、同时静音，系统照常运行**。恢复时取消静音并点亮屏幕。

只做这一件事。无安装、无服务、无开机自启、无网络。

## 它解决什么问题

**场景**：想让电脑"看起来是关着的"，但机器其实要继续跑 —— 下载/上传、编译、挂机任务、远程连回来、夜里不想被屏幕光晃、会议时不想屏幕突然亮起来。

系统自带的办法都不够用：

| 常规做法 | 为什么不够 |
|---|---|
| 按显示器电源键 | 显示器进待机，但 Windows 仍以为屏幕活着；动一下鼠标、来一个通知、某个程序要求常亮，就亮了，而且不会自己再黑 |
| 电源计划「闲置 N 分钟关闭显示器」 | 要等；一动鼠标就恢复；做不到"现在就黑、并且一直黑" |
| Win+L 锁屏 | 屏幕照样亮 |
| 合盖 | 很多机器是睡眠，系统直接停 |
| 其他"关屏"小工具 | 大多只发一次关屏命令，之后谁点亮就亮着；有的还要装驱动 / 服务 / 开机自启 |

**这个工具解决的正是这些：**

- **立刻黑**：热键一按就黑，不用等闲置超时。
- **一直黑**：没有人碰输入、且距上次灭屏满 6 秒，才补发一次灭屏（锁鼠标模式放宽到 30 秒）。**动鼠标时不会反复关屏，所以不会闪**；画面亮着也只是因为你在操作，停手 2 秒就黑。
- **声音一起断**：关屏同时把默认播放设备静音，避免"屏幕黑了还在出声"；运行中每 5 秒复查，被手动取消静音会重新压回去。
- **一键还原**：`Alt+3` = 停循环 + 取消静音 + 点亮屏幕，一步到位；托盘双击也是还原。
- **两种强度**：静默模式谁都能点亮（亮 0.5 秒又灭）；锁鼠标模式连物理鼠标 / 触摸板都点不亮，只有键盘能点亮，远程注入的鼠标不受影响。
- **不留尾巴**：不安装、不注册服务、不写开机自启、不联网；正常退出会自己恢复静音和屏幕。

**它不做什么**（边界，避免误期待）：

- 不阻止程序强制常亮（`SetThreadExecutionState`）：只能 15 秒内再灭一次，做不到"任何程序都点不亮"。
- 不是锁屏 / 加密，别人仍可解锁使用电脑。
- 不隐藏进程：托盘图标一直在，随时能退出。

## 用法

1. 下载 `ScreenOff.exe`，双击运行（首次可能弹防火墙/未知发布者提示，选允许即可）。
2. 首次运行会**自动弹出界面窗口**；关掉窗口不退出，程序缩到托盘继续跑。

### 界面

一个窗口就够用，上面有五样东西：

- **当前状态**：未启用 / 静默中 / 锁鼠标中
- **① 开始 · 静默模式**、**② 开始 · 锁鼠标模式**、**③ 恢复屏幕** 三个按钮，作用和热键完全一样
- **关屏时同时静音** 复选框（会记住你的选择，存在 `%LOCALAPPDATA%\ScreenOff\settings.ini`）
- **状态行**：热键是否就绪、灭屏指令发了多少次、当前是否静音
- **日志预览**（最近 20 行）+ **打开日志文件夹**

热键随时可以把窗口叫出来：**Alt+0**。托盘图标双击也是打开界面。

> 锁鼠标模式下鼠标动不了，但**窗口在前台时钩子会放行鼠标** —— 所以按 Alt+0 把窗口叫到最前，就能用鼠标点按钮；点了它以外的范围又会恢复锁鼠标。

| 热键 | 作用 |
|---|---|
| **Alt+0** | 打开界面窗口 |
| **Alt+1** | 开始 · 静默模式（不拦输入，谁点亮都在 0.5 秒内补灭） |
| **Alt+2** | 开始 · 锁鼠标模式（吞掉物理鼠标/触摸板，键盘照常能点亮；**想让动鼠标也不亮就用这个**） |
| **Alt+3** | 恢复（停循环 + 取消静音 + 点亮屏幕） |

托盘图标：单击展开菜单（打开界面 / 静默 / 锁鼠标 / 恢复 / 退出）。

退出程序：界面右上角 × 只是隐藏，要退出用托盘菜单 → 退出，或界面里没有的（关窗口 = 隐藏）。彻底退出时会自动恢复静音和屏幕。

## 行为细节

- **关屏**：广播 `WM_SYSCOMMAND / SC_MONITORPOWER`。
- **不再高频发命令**：只有检测到输入（`GetLastInputInfo` 变化）后的 0.5 秒才补灭一次，另有 15 秒兜底，避免显示器因重复命令闪烁。
- **静音**：切系统默认播放设备静音；运行期间每 5 秒复查，被手动取消就重新静音；恢复/退出时取消静音。
- **锁鼠标模式**：低级鼠标钩子（`WH_MOUSE_LL`）吞掉物理鼠标事件；远程桌面/串流软件**注入**的鼠标事件放行，不影响远程操作；键盘从不拦截。
- **进程被杀**：关掉托盘/结束进程时，退出流程会取消静音并点亮屏幕；若被强杀，按一下键盘即可点亮，声音需要手动恢复。

## 文件

| 文件 | 作用 |
|---|---|
| `src/MainForm.cs` | 主界面窗口（状态、三个按钮、静音开关、状态行、日志预览） |
| `src/TrayContext.cs` | 托盘、模式切换、灭屏调度、静音守护、设置持久化、单实例 |
| `src/HotkeyWindow.cs` | 全局热键 Alt+0/1/2/3 |
| `src/Native.cs` | 关屏/点亮/热键/空闲检测/前台窗口的 P/Invoke |
| `src/AudioMute.cs` | CoreAudio 静音开关 |
| `src/MouseBlocker.cs` | 锁鼠标模式的低级鼠标钩子（界面在前台时放行） |
| `src/Program.cs` | 入口 + 单实例互斥 |

日志：`%LOCALAPPDATA%\ScreenOff\screenoff.log`　设置：`%LOCALAPPDATA%\ScreenOff\settings.ini`

## 构建

全部走 GitHub Actions（本地不构建）：

- 工作流：`.github/workflows/build.yml`
- 触发：push 到 `main`/`master`，或在 Actions 页 `workflow_dispatch`
- 产物：`ScreenOff-win-x64` artifact 里的 `ScreenOff.exe`（自包含单文件，目标机不需要装 .NET）

环境：.NET 8 + WinForms + `win-x64`，`PublishSingleFile` + 压缩。
